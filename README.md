# 📚 Athenaeum Library Management System

**Athenaeum** is a desktop-based Library Management System designed to simplify everyday library operations through an intuitive interface and a clean, elegant design.

The application provides a convenient way to manage library resources, member information, and borrowing activities in one place.

## ✨ Features

* 🔐 **Login System** — Secure access to the application with input validation.
* 📊 **Dashboard** — An overview of important library information.
* 📚 **Book Management** — Add and manage book records.
* 👥 **Member Management** — Register, search, edit, and remove member records.
* 📖 **Book Borrowing** — Issue books and manage borrowing details.
* 🔄 **Book Returns** — Process returns and track overdue books.
* 📋 **Borrowing History** — Keep track of borrowing activities.
* 🎨 **User-Friendly Interface** — A clean design with a consistent library-inspired theme.

## 🛠️ Built With

* Java
* JavaFX
* FXML
* CSS

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to load the required dependencies.
4. Run the main application class to launch Athenaeum.

Ensure you have a compatible JDK and the required project dependencies configured before running the application.
